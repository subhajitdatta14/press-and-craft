# 🖋️ PRESS & CRAFT

## ✨ Overview

**PRESS & CRAFT** is an interactive web-based typewriter inspired by the **1874 Sholes & Glidden Type Writer**, manufactured by **E. Remington & Sons**.

The project recreates the character of early mechanical typing through an interactive keyboard, carriage movement, paper feeding, margin controls, mechanical sounds, vintage typography, and a period-inspired visual design.
It combines the charm of a historic writing machine with the convenience of a modern browser.

---

## 🏛️ Key Features

- 🎹 **Authentic Mechanical Feedback:**
  - Responsive typewriter keystrokes with genuine per-key audio acoustics.
  - Platen advance and mechanical carriage return arm with authentic brass bell warning chime.
  - Tactile Shift lock, backspace, and mechanical paper feed knob controls.

- 📜 **Tactile Manuscript & Paper Simulation:**
  - Real-time ink imprint rendering with vintage typewriter typography (`Special Elite` & `Courier Prime`).
  - True-to-life paper margins, platen scrolling, and ink density variation.
  - Distraction-free full manuscript view and paper expansion mode.

- 🖨️ **Print & Archival Export:**
  - Direct export to **PDF Document** with authentic parchment aesthetics.
  - One-click native **Print** layout pre-styled for physical letter-press printing.
  - Automatic persistent session preservation — your writing stays safely stored across browser refreshes.

- 🎨 **Artisanal Victorian Design:**
  - Custom cast-iron body finish, hand-painted gold filigree accents, and authentic vintage brass badges.
  - Zero-latency typeface loading with seamless cover reveal.

## 🕹️ Keyboard Controls & Shortcuts

| Key / Action | Function |
| :--- | :--- |
| **Typing Keys (`A–Z`, `0–9`, punctuation)** | Types characters with mechanical typebar sound & carriage step |
| **`Enter` / Carriage Return Lever** | Rings margin bell, steps platen, and returns carriage to start |
| **`Backspace`** | Steps carriage back one character position |
| **`Shift`** | Engages upper-case character basket |
| **`Spacebar`** | Advances carriage one space silently with mechanical escapement click |
